# Styled Markdown is now Semantic Markdown

This extension has a new name and a new ID: **[Semantic Markdown](https://marketplace.visualstudio.com/items?itemName=bislink360.semantic-markdown)** (`bislink360.semantic-markdown`).

This last update of the old entry installs Semantic Markdown for you. It does nothing else, so you can uninstall it afterwards. Your `.smd` files, your `smd.*` settings and your keybindings keep working as before, because the new extension uses the same file type, settings and commands.

To switch by hand:

```bash
code --install-extension bislink360.semantic-markdown
code --uninstall-extension bislink360.styled-markdown
```

See the [changelog](https://github.com/bislink360/semantic-markdown/blob/main/extension/CHANGELOG.md) for what changed in 3.0.
